## What's Next

### Immediate Next Steps (This Week)

1. **Firebase Project Setup** (1-2 hours)
   ```bash
   # Install Firebase CLI
   npm install -g firebase-tools
   dart pub global activate flutterfire_cli
   
   # Login and configure
   firebase login
   flutterfire configure
   ```

2. **Download Firebase Config Files**
   - Create Firebase project in console
   - Download `google-services.json` → `android/app/`
   - Download `GoogleService-Info.plist` → `ios/Runner/`

3. **Deploy Security Rules**
   ```bash
   firebase init firestore
   firebase deploy --only firestore:rules
   firebase deploy --only storage
   ```

4. **Test Firebase Connection**
   - Update `lib/main.dart` to initialize Firebase
   - Run app and verify console shows "Firebase initialized successfully"

## Architecture Decisions

Refer to these ADRs for context on key decisions:

1. **ADR 0001:** Firebase Free Tier Architecture
   - Manual admin workflows
   - In-app notifications only
   - Clear upgrade path to Blaze

2. **ADR 0002:** Phone OTP + Google Sign-In
   - Passwordless authentication
   - Mobile-first approach

3. **ADR 0003:** Single Community Group Chat
   - Simplicity over fragmentation
   - Easy moderation
